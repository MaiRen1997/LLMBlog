## MCP Server

[MCP笔记](https://mairen1997.github.io/LLMBlog/pages/eaefd2/#mcp%E6%9E%B6%E6%9E%84)

1. 使用`FastMCP("Demo"， host="0.0.0.0", port=8000)`定义名称、IP、端口号

   1. 如果类型是sse，需要指定IP和端口
   2. 如果是stdio，则不需要指定 通过**本地进程**(stdio)通信。Client 启动 Server 为子进程，两者通过标准输入输出流传递数据

2. 使用`@实例名称.tool()`添加工具

3. 使用`实例名称.run(transport="stdio")`或者`实例名称.run(transport="sse")`运行

4. ```python
   # pip install mcp
   # pip install pywin32
   from mcp.server.fastmcp import FastMCP
   
   # 创建 MCP 实例
   mcp = FastMCP("weather"， host="0.0.0.0", port=8000)
   
   # 为 MCP 实例添加工具
   @mcp.tool()
   def add(a: int, b: int) -> int:
       return a + b
   
   # 为 MCP 实例添加资源
   @mcp.resource("greeting://default")
   def get_greeting() -> str:
       return "Hello from static resource!"
   
   # 为 MCP 实例添加提示词
   @mcp.prompt()
   def greet_user(name: str, style: str = "friendly") -> str:
       styles = {
           "friendly": "写一句友善的问候",
           "formal": "写一句正式的问候",
           "casual": "写一句轻松的问候",
       }
       return f"为{name}{styles.get(style, styles['friendly'])}"
   
   if __name__ == "__main__":
       mcp.run(transport="sse")
   
   
   """
   import pywintypes
   ModuleNotFoundError: No module named 'pywintypes'
   
   
   方案 2：等待 pywin32 适配 Python 3.13（被动，无需改动环境）

## MCP Client

### 定义json配置

```
文件名为mcp.json，可以定义其他文件名，不做限制
{
    "mcpServers":{
        "weather":{
            "url": "http://127.0.0.1:8000/mcp",
            "description": "用来查询天气",
            "transport":"sse"
        }
    }
}
```

### 定义MCP Client

```python
from langchain_mcp_adapters.client import MultiServerMCPClient
from langchain.agents import create_agent
from utilFunction import load_servers
# 提取配置
configJson = load_servers()
#导入配置
client = MultiServerMCPClient(configJson)

tools = await client.get_tools()
# 创建智能体
agent = create_agent("openai:gpt-4.1", tools)
response = await agent.ainvoke({"messages": "what is the weather in nyc?"})
```
