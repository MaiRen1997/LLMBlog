## 消息类型

| 消息类型              | 对应角色               | 描述与用途                                                   |
| :-------------------- | :--------------------- | :----------------------------------------------------------- |
| **`SystemMessage`**   | **system**             | 用于设定语言模型的行为和上下文，通常放在对话序列的开头。它可以定义模型的角色（例如“你是一位专业的旅游顾问”）、设定回答的语气（如“请用简洁的方式回答”）或提供基本的指导规则。 |
| **`HumanMessage`**    | **user** / **human**   | 代表用户（人类）的输入，是模型需要响应的主要信息来源。这是对话中最常见的消息类型。 |
| **`AIMessage`**       | **assistant** / **ai** | 代表语言模型（AI）生成的响应。它可以是文本，也可以是调用工具的请求（`tool_calls`）。 |
| **`ToolMessage`**     | **tool**               | 代表工具执行后返回的结果。当模型调用一个工具（例如，查询天气、进行计算）时，工具的执行结果会通过`ToolMessage`传回给模型，以便模型根据结果生成最终回答。 |
| **`FunctionMessage`** | **function**           | 这是一个**遗留角色**，对应OpenAI早期的函数调用API。现在官方已推荐使用功能更强大的`ToolMessage`来替代它。 |

## 使用方式

- 方式一需要`引入包`，方式二不需要
- 方式一是静态的，方式二需要在运行时，`通过langChain的内部机制转换成Message类对象`
- `方式二`由于需要二次转换，因此`可以在消息中使用变量`

### 方式一:

```python
from langchain_core.messages import (
    AIMessage, 
    HumanMessage, 
    SystemMessage,
    ToolMessage,
    FunctionMessage
)
messages = [
    SystemMessage(content="你是一个助手，可以使用函数回答问题。"),
    HumanMessage(content="北京今天天气怎么样？")
]
```

### 方式二:

```python
messages = [
    ('system', "你是一个助手，可以使用函数回答问题。"),
    ('user', "{city}今天天气怎么样？")
]
```
