## 概述

### 代码说明

1. 直接通过`graph实例.update_state`更新state数据

   1. 第一个参数是config，里面包含对话的id,用于避免混乱
   2. 第二个参数是需要更新的数据，以字典的方式传入

2. ```python
   config = {"configurable": {"thread_id": "test-thread-1"}}
   graph.update_state(config, {"user_input": user_input})
   ```
