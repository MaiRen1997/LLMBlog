### XPath 定位

XPath 是 W3C 制定的、用来在 XML/HTML 文档中选择节点的语言。Playwright 的 `locator()` 参数也可以直接写 XPath：

```Python
# CSS 写法
page.locator('[href="http://www.miitbeian.gov.cn"]')

# 等价的 XPath 写法
page.locator('//*[@href="http://www.miitbeian.gov.cn"]')
```

XPath 表达能力很强，但语法相对复杂。在大多数场景下 CSS 选择器够用了。

### Playwright 更推荐的定位方式

CSS 选择器 / XPath 都是根据 HTML 元素特征的定位，属于开发者视角。Playwright 更推荐从**用户视觉视角的定位方式，因为用户感知到的内容相对更稳定，不容易因 HTML 结构变化而失效。

但用户视觉定位也有局限——不是所有元素都有合适的视觉特征。所以开发者角度的定位仍然要学。

### 根据文本内容定位

```Python
# 文本包含
locs = page.get_by_text('11').all()

# 以指定正则匹配
import re
locs = page.get_by_text(re.compile('11$')).all()
```

### 根据元素 Role 定位

ARIA（Accessible Rich Internet Applications）是 Web 无障碍访问标准，它为 Web 元素定义了角色（role）信息，让辅助技术能够识别和操作 Web 元素。

```Python
# 根据 role 定位一条警告信息
page.get_by_role('alert').inner_text()

# 根据 role + 可访问名称定位链接
page.get_by_role('link', name='白月黑羽教程').click()

# 精确匹配（默认不区分大小写、可部分匹配
page.get_by_role('link', name='白月黑羽', exact=True)

# 正则匹配
page.get_by_role('link', name=re.compile('^白月.*羽'))

# 标题 level
page.get_by_role('heading', level=2).inner_text()
```

常见元素自带的可访问名称（Accessible Name）规则：

- `<a>` `<td>` `<button>`：内部文本
- `<input>` `<textarea>`：与之关联的 label 文本
- `<img>`：alt 属性值

新手可以通过 codegen 助手自动生成 role 定位代码，非常方便。

### 其他用户视觉定位方法

```Python
# 根据 placeholder 定位输入框
page.get_by_placeholder('captcha', exact=True).fill('白月黑羽')

# 根据 label 定位输入框
page.get_by_label('Username').fill('john')
page.get_by_label('Password').fill('secret')

# 根据 alt text 定位图片
href = page.get_by_alt_text('qt-button').get_attribute('src')

# 根据 title 属性定位
page.get_by_title('byhy首页').click()
```

这些方法都有 `exact` 参数：`True` 表示精确匹配且区分大小写；`False` 表示包含匹配且不区分大小写。

### 缺省等待时间

Playwright 在对元素进行操作时，如果根据定位条件找不到元素，**默认会等待最多 30 秒**。在这 30 秒内如果元素出现，则立即操作成功。

```Python
# 单次操作指定超时
page.locator('[id="1"]').inner_text(timeout=10)

# 全局修改缺省等待时间
from playwright.sync_api import sync_playwright

p = sync_playwright().start()
browser = p.chromium.launch(headless=False, slow_mo=50)
context = browser.new_context()
context.set_default_timeout(10)
page = context.new_page()
```

> 说明：不像 Selenium 经常要手动设置隐式等待，Playwright 默认就有 30 秒智能等待，这是一大优点。

**小结**：推荐定位优先级 —— CSS/XPath → Role（角色/可访问名称） → 文本内容 → 其他视觉定位。初学者先用 CSS/XPath，熟练后可结合 Role 写出更稳定的定位代码。
