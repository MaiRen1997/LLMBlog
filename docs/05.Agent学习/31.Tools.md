## 如何构建tools

### 方式一:通过装饰

1. 通过装饰器的方式去定义，在函数上面添加`@tool`装饰器

2. 需要在args上加上类型说明

   1. 使用typed hint(也就是base:int 的这种类型推断)
   2. 使用Pydantic

3. 需要在逻辑前面，添加description

   ```python
   from langchain.tools import tool
   
   @tool
   def add_number(a: int, b: int) -> int:
       """两个整数相加"""
       return a + b
   
   print(add_number.name)
   print(add_number.description)
   print(add_number.args)
   ```

   class SearchInput(BaseModel):

## 如何调用tool

### 特别提醒

1. 如果使用langchain框架，定义agent，如下方式不需要手动做
   1. 手动调用工具获取结果
   2. 将工具结果返回给大模型也不需要做

### 使用invoke

通过调用invoke去执行tool当中的逻辑，invoke传入一个dict，dict的键就是tool的入参，值就是参数的值

```python
add_number.invoke({"a": 10, "b": 20})
```

## 如何让大模型感知tool

### 使用bind_tools

1. 当前AI无法自动调用工具，需要AI手动调用工具

```python
tools = [query_user_info]

llm_with_tools = llm.bind_tools(tools)

resp = llm_with_tools.invoke("帮我查下1001用户的信息")
print(resp)

# content='\n\n我来帮您查询1001用户的信息。\n'
# additional_kwargs={'tool_calls': [{'id': '...', 'function': {'arguments': '{"user_id": 1001}', 'name': 'query_user_info'}

# 返回的响应中 additional_kwargs 参数中包括了工具调用的信息，此时还没有调用工具，只是返回了要调用的工具及参数

# 手动执行工具
for tool_call in resp.tool_calls:
    tool_name = tool_call["name"]  # 获取工具名称
    tool_args = tool_call["args"]  # 获取工具参数
    tool_result = globals()[tool_name].invoke(tool_args)  # 执行工具
    print(tool_name, tool_args, tool_result)

```
