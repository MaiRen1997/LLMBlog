    frame与tab切换

    # frame 切换

    HTML 页面中可能会嵌入 <iframe> 元素，iframe 内部是一份被嵌入的独立 HTML 文档。

    在 Playwright 中，默认的操作范围是当前主页面的 HTML，不包括被嵌入文档中的内容。要操作 iframe 内的元素，必须先用 frame_locator 切换到目标 frame：

    from playwright.sync_api import sync_playwright

p = sync_playwright().start()
browser = p.chromium.launch(headless=False)
page = browser.new_page()
page.goto("https://www.byhy.net/cdn2/files/selenium/sample2.html")

# 产生一个 FrameLocator 对象
frame = page.frame_locator("iframe[src='sample1.html']")

# 再在其内部定位
locs = frame.locator('.plant').all()
for lc in locs:
    print(lc.inner_text(timeout=1000))

    frame_locator 的参数可以是 CSS 或 XPath 选择器，只要能定位到 iframe 元素即可。

    # 窗口 / Tab 切换

    点击链接打开新窗口时，page 变量对应的仍是老窗口。如果要在新窗口中操作，需要通过 BrowserContext 来管理多个窗口：

    from playwright.sync_api import sync_playwright

pw = sync_playwright().start()
browser = pw.chromium.launch(headless=False)

# 创建 BrowserContext 对象
context = browser.new_context()

# 通过 context 创建 page
page = context.new_page()
page.goto("https://www.byhy.net/cdn2/files/selenium/sample3.html")

# 点击链接，打开新窗口
page.locator("a").click()

# 等待 2 秒（不能用 time.sleep
page.wait_for_timeout(2000)

# pages 属性是所有窗口对应 Page 对象的列表
new_page = context.pages[1]

# 打印新窗口标题
print(new_page.title())
# 打印原窗口标题
print(page.title())

    如果新窗口序号不确定，可以通过标题来定位：

    for pg in context.pages:
    if '必应' in pg.title():
        print(pg.title())
        break

    # 冻结界面（调试技巧

    某些元素在鼠标移开后会消失（例如百度首页的「更多」下拉），导致难以在开发者工具栏中查看其 HTML。

    可以在 Console 中执行：

    setTimeout(function(){debugger}, 5000)

    5 秒后进入 debugger 状态，此时页面被冻结——不管怎么操作界面都不会响应事件。

    这样就有时间把鼠标移到目标元素上，等 5 秒冻结后再去查看 HTML。

    # 截屏当前可见内容
page.screenshot(path='ss1.png')

# 截屏整个页面（包含不可见区域，长页面也能完整截取
page.screenshot(path='ss1.png', full_page=True)

# 只对某个元素截屏
page.locator('input[type=file]').screenshot(path='ss2.png')

    # 拖拽

    # 方法一：通过 Page 的 drag_and_drop
page.locator('#t1').select_text()
page.drag_and_drop('#t1', '[placeholder="captcha"]')

# 方法二：通过 Locator 的 drag_to
lc = page.locator('#t1')
lc.select_text()
lc.drag_to(page.locator('[placeholder="captcha"]'))

    注意：drag_to 的参数是目标元素的 Locator 对象，而不是选择器字符串。

    # 弹出对话框（alert / confirm / prompt）

    网页的三种弹出框在 Playwright 中统一用 Dialog 事件处理：

    from playwright.sync_api import sync_playwright

pw = sync_playwright().start()
browser = pw.chromium.launch(headless=False)
page = browser.new_page()
page.goto("https://www.byhy.net/cdn2/files/selenium/test4.html")

# 处理弹出对话框的回调函数
def handle_dialog(dialog):
    page.wait_for_timeout(1000)
    dialog.accept()              # 点击确定
    # dialog.dismiss()           # 点击取消
    # dialog.accept('你好啊')     # prompt 框时可输入内容
    print(dialog.message)        # 打印框内提示文本

# 注册事件
page.on('dialog', handle_dialog)

# 点击按钮触发弹窗
page.locator('#b1').click()   # alert
page.locator('#b2').click()   # confirm
page.locator('#b3').click()   # prompt

    注意事项：

    • 注册的处理函数中必须调用 accept 或 dismiss，否则页面会被卡住，后续代码也不会执行，且会产生超时错误。
    • 如果没有注册任何 dialog 处理函数，Playwright 会自动点击「取消」来关闭对话框。
