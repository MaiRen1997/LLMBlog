字符串输出解析器

# StrOutputParser字符串输出解析器

如果想要以第一次模型的输出结果，第二次去询问模型

# 错误分析

错误代码

chain = prompt | model | model

错误原因：

  1. prompt的结果是PromptValue类型，才能输入给了model
  2. 但是第一个 model的输出结果是：AIMessage
  3. model只能接收PromptValue | str | Sequence[MessageLikeRepresentation]

# 使用方式

只需要将：

chain = prompt | model | model

改成:

parser =StrOutputParser()
chain = prompt | model | parser | model

# 详细说明

Str0utputParser是LangChain内置的简单字符串解析器

  1. 可以将AIMessage解析为简单的字符串，符合了模型invoke方法要求(可传入字符串，不接收AIMessage类型)
  2. 是Runnable接口的子类(可以加入链)
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import PromptTemplate
from langchain_community.chat_models.tongyi import chatTongyi

parser =StrOutputParser()
model= ChatTongyi(model="qwen3-max")
prompt =PromptTemplate.from template("我邻居姓:{lastname}，刚生了{gender}，请起名，仅告知我名字无需其它内容。
chain = prompt | model | parser | model
res = chain.invoke({"lastname":"张"，"gender":"女儿"})
print(res.content)
