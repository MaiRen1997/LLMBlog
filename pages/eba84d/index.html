安装及基本使用

# Playwright 简介

Playwright 是微软开发的 Web 应用自动化测试框架。和 Selenium 相比，Playwright 除了支持 Web 自动化外，还内置了自动化测试功能框架；而且自动化原理也有些差异。

# 安装 Playwright 客户端库

pip install playwright

# 安装浏览器

/img/0622.mov 执行 playwright install，会自动下载 Chromium、Firefox、WebKit 三个浏览器。

如果只需要一个浏览器，可指定安装：

playwright install chromium

注意：Playwright 也可以驱动已经安装好的品牌浏览器（Chrome、Edge、Firefox 等），后文会讲到。

品牌浏览器往往会自动更新。如果使用 Selenium 自动化，就需要不断下载新的驱动。而 Playwright 使用自编译浏览器不会自动更新，避免驱动和浏览器版本不匹配的问题。

# 简单示例

# 基础代码

from playwright.sync_api import sync_playwright

# 启动 playwright driver 进程

p = sync_playwright().start()

# 启动浏览器，返回 Browser 类型对象

browser = p.chromium.launch(headless=False)

# 创建新页面，返回 Page 类型对象

page = browser.new_page()
page.goto("https://www.byhy.net/cdn2/files/selenium/stock1.html")
print(page.title())  # 打印网页标题

# 输入通讯，点击查询

page.locator('#kw').fill('通讯')
page.locator('#go').click()

# 打印所有搜索内容

lcs = page.locator(".result-item").all()
for lc in lcs:
    print(lc.inner_text())

# 关闭浏览器

browser.close()

# 关闭 playwright driver 进程

p.stop()

# 切换其他浏览器

# 启动 firefox
browser = p.firefox.launch(headless=False)

# 启动 webkit
browser = p.webkit.launch(headless=False)

# 指定浏览器

通过 executable_path 指定本机已安装的浏览器

browser = p.chromium.launch(
    headless=False,
    executable_path='c:\\Program Files\\Google\\Chrome\\Application\\chrome.exe'
)

# with as的使用

使用 with as 会话管理，可以让代码更简洁，无需手动调用 start() 和 stop()

from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch(headless=False)
    page = browser.new_page()
    page.goto("https://www.byhy.net/cdn2/files/selenium/stock1.html")
    print(page.title())
    page.locator('#kw').fill('通讯\n')
    page.locator('#go').click()
    lcs = page.locator(".result-item").all()
    for lc in lcs:
        print(lc.inner_text())
    browser.close()

# 界面等待

上面的代码并不能打印出股票搜索结果，因为点击查询后立即检查，此时页面还没来得及呈现结果。

需要等待一段时间，但在 Playwright 中 不能使用 time.sleep，否则会破坏异步事件处理逻辑。应使用 wait_for_timeout 方法，单位毫秒：

page.wait_for_timeout(1000)

# 自动化代码助手（codegen）

这个工具只能作为助手使用，主要是记录对页面的操作；对于像 print(page.title()) 或遍历搜索结果这样的「获取页面信息」类代码，还是需要自己手写。

# 跟踪功能（Tracing）

启用跟踪功能后，可以在执行完自动化后，回看执行过程中的每一个细节。这对测试失败时的调试非常有用。

from playwright.sync_api import sync_playwright

p = sync_playwright().start()
browser = p.chromium.launch(headless=False)

# 创建 BrowserContext 对象
context = browser.new_context()
# 启动跟踪功能
context.tracing.start(snapshots=True, sources=True, screenshots=True)

page = context.new_page()
page.goto("https://www.byhy.net/cdn2/files/selenium/stock1.html")

# 搜索名称中包含 通讯 的股票
page.locator('#kw').fill('通讯')
page.locator('#go').click()
page.wait_for_timeout(1000)

lcs = page.locator(".result-item").all()
for lc in lcs:
    print(lc.inner_text())

# 搜索名称中包含 软件 的股票
page.locator('#kw').fill('软件')
page.locator('#go').click()
page.wait_for_timeout(1000)

lcs = page.locator(".result-item").all()
for lc in lcs:
    print(lc.inner_text())

# 结束跟踪
context.tracing.stop(path="trace.zip")

browser.close()
p.stop()

查看 trace.zip 的两种方法：

  1. 访问 上传跟踪文件
  2. 执行 playwright show-trace trace.zip
