# Annotated

Annotated格式：

Annotated[类型，元数据1，元数据2........]

  1. 基础类型式必须遵守的，元数据是：对这个字段的补充说明/规则配置
  2. 元数据可以是任意内容：字符串、数字、函数、lambda表达式，自定义对象等

# TypeDict+Annotated

  1. Annotated 本身不具备运行时校验能力，其只是给类型 “加注释”，不是给类型 “加校验规则”
  2. 即使类型不一致，也不会报错，不会影响运行，因此功能不好用
from typing import Annotated, TypedDict

Age = Annotated[int, "年龄，范围0-150"]

class Person(TypedDict):
    name: str;
    age: int;
    age2:Age;

p = Person(name="z3",age=111,age2=188)
print(p)

# p = Person(name="z3",age="1111")
# print(p)

添加后也不报错，只是额外多加了注释

# pydantic + Annotated

# 二者结合

用Annotated结合Field设置范围约束，兼具注释和运行时校验能力

from typing import Annotated
from pydantic import BaseModel, Field, ValidationError

# 用Annotated结合Field设置范围约束，兼具注释和运行时校验能力
Age = Annotated[int, Field(ge=0, le=150, description="年龄，范围0-150")]

class Person(BaseModel):
    name: str
    age: int
    age2: Age

try:
    p = Person(name="z3", age=11, age2=188)
    print(p)
except ValidationError as e:
    print("数据校验失败：")
    print(e)
