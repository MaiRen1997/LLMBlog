    css选择器

    # 定位元素的重要性

    做 Web 界面自动化，要对界面进行操作，首先需要定位到界面元素——告诉浏览器你要操作的元素特征，让它先找到那个元素，然后才能进行操作。

    相对于操作方法（click、fill、inner_text 等），定位元素更难一些。

    # CSS Selector 定位原理

    HTML 中为某些元素指定显示效果时，会用 CSS 选择器选择元素。既然 CSS Selector 天生就是浏览器用来选元素的，Playwright 自然也可以用它来做自动化定位。

    只要 CSS Selector 语法正确，Playwright 就能选到目标元素。

    # Locator 对象

    Playwright 中根据 CSS Selector 选择元素，是通过 Locator 类型对象完成的：

    page.locator('#kw').fill('通讯')
page.locator('#go').click()

    page.locator(selector) 会根据选择器表达式创建一个 Locator 对象。如果定位到多个元素，可以调用 .all() 拿到所有元素的 Locator 列表。

    # 根据 tag 名 / id / class 选择元素

    # 根据 tag 名选择
locs = page.locator('div').all()

# 根据 id 选择（井号前缀）
page.locator('#searchtext').fill('你好')

# 根据 class 选择（点前缀）
page.locator('.animal').all()

# 元素有多个 class 值时，同时匹配多个 class
page.locator('.chinese.student')

    # 验证 CSS Selector

    在浏览器开发者工具栏（F12 → Elements）中按 Ctrl + F，输入 CSS Selector 表达式，如果能匹配到元素，右侧会显示「共匹配 N 个元素，当前高亮第 M 个」。

    # 匹配多个元素

    # 获取多个元素
locs = page.locator('.plant').all()

# 只获取元素数量
count = page.locator('.plant').count()

# 第一个 / 最后一个
locs.first.inner_text()
locs.last.inner_text()

# 指定索引（0 表示第一个）
locs.nth(1).inner_text()

    # 元素内部定位

    在某个元素范围内继续定位，可以通过 Locator 继续调用 locator：

    outer = page.locator('#bottom')
locs = outer.locator('span').all()
for lc in locs:
    print(lc.inner_text())

    # 选择子元素和后代元素

    # 直接子元素（一层）
page.locator('#container > .layer')

# 后代元素（任意层级）
page.locator('#container .item')

# 多层嵌套
page.locator('#a > #b > #c .d')

    # 根据属性选择

    # 精确匹配 href 值
page.locator('[href="http://www.miitbeian.gov.cn"]')

# 标签 + 属性
page.locator('a[href="http://www.miitbeian.gov.cn"]')

# 包含某个字符串
page.locator('a[href*="miitbeian"]')

# 以某个字符串开头
page.locator('a[href^="http"]')

# 以某个字符串结尾
page.locator('a[href$="gov.cn"]')

# 多个属性同时满足
page.locator('div[class=misc][ctype=gun]')

    # 选择语法联合使用

    # 在 footer 范围内，class 为 copyright 且 name 为 cp1 的元素
page.locator('.footer1 > .copyright[name=cp1]')

    # 组选择

    用逗号分隔多个选择器，一次选中所有匹配元素（按在 HTML 中出现的顺序排序）：

    locs = page.locator('.plant, .animal').all()
locs = page.locator('div, #BYHY').all()

    注意：组选择的结果次序是元素在 HTML 文档中出现的自然次序，而不是选择器书写次序。

    # 按次序选择子节点

    # 父元素的第 n 个子节点（所有类型一起数）
page.locator('span:nth-child(2)')

# 倒数第 n 个
page.locator('p:nth-last-child(1)')

# 父元素的第 n 个某类型子节点
page.locator('span:nth-of-type(1)')

# 倒数第 n 个某类型子节点
page.locator('p:nth-last-of-type(2)')

# 偶数位置
page.locator('p:nth-child(even)')

# 奇数位置
page.locator('p:nth-child(odd)')

    # 兄弟节点选择

    相邻兄弟节点用 + 分隔：

    # 紧跟在 h3 后面的 span
page.locator('h3 + span')

    非相邻的后续兄弟节点用 ~ 分隔：

    # h3 之后的所有同级 span
page.locator('h3 ~ span')
