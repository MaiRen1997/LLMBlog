# 长期会话记忆

FileChatMessageHistory类实现，核心思路:

  • 基于文件存储会话记录：以session id为文件名，不同session id有不同文件存储消息

继承BaseChatMessageHistory实现如下3个方法:

  1. add messages:同步模式，添加消息
  2. messages:同步模式，获取消息
  3. clear:同步模式，清除消息

如右侧代码，官方在BasechatMessageHistory类的注释中提供了一个基于文件存储的示例代码。
