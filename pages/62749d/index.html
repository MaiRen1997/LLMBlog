(步骤二)RAGFlow暴露接口供python调用

提供了两种方式供你选择：

# 🎯 两种 Python 接入方式

方式 推荐程度 特点 适用场景
官方 Python SDK (ragflow-sdk) ⭐⭐⭐⭐⭐ 封装良好，开箱即用，代码简洁 大多数二次开发场景，如构建自定义工作流、自动化数据处理
原生 HTTP API ⭐⭐⭐⭐ 更底层，灵活性最高 需要精细控制请求细节，或 SDK 暂未覆盖的功能

# 方式一：使用官方 Python SDK（推荐）

# 1. 安装 SDK

bash

pip install ragflow-sdk

官方 SDK 已在 PyPI 发布，可直接通过 pip 安装。

# 2. 初始化客户端

python

from ragflow_sdk import RAGFlow

# 初始化连接
rag_object = RAGFlow(
    api_key="YOUR_API_KEY",           # 在 RAGFlow 控制台获取
    base_url="http://your-ragflow-address:9380"  # 你的 RAGFlow 服务地址
)

获取 API Key：登录 RAGFlow → 右上角头像 → API → 获取 API Key。

# 3. 核心功能示例

# 创建知识库

python

# 创建数据集（知识库）
dataset = rag_object.create_dataset(
    name="my_knowledge_base",
    description="这是我的知识库",
    embedding_model="BAAI/bge-large-zh-v1.5@BAAI"  # 指定嵌入模型
)
print(f"创建成功，数据集ID: {dataset.id}")

# 列出所有知识库

python

# 列出所有数据集
for dataset in rag_object.list_datasets():
    print(f"名称: {dataset.name}, ID: {dataset.id}, 文档数: {dataset.document_count}")

# 上传文档到知识库

python

# 获取数据集对象
dataset = rag_object.list_datasets(id="your_dataset_id")[0]

# 上传文档
with open("example.pdf", "rb") as file:
    dataset.upload_documents(
        file=file,
        name="example.pdf",
        chunk_method="naive"  # 分块方法
    )

# 对话检索（核心功能）

RAGFlow 提供了 OpenAI 兼容的对话 API，可以直接用 OpenAI 客户端调用：

python

from openai import OpenAI

# 注意：这里的 base_url 指向特定的 chat_id
client = OpenAI(
    api_key="ragflow-api-key",
    base_url="http://your-ragflow-address/api/v1/chats_openai/<your_chat_id>"
)

# 发起带知识库检索的对话
response = client.chat.completions.create(
    model="model",  # 任意值即可，服务端会自动处理
    messages=[
        {"role": "user", "content": "请介绍一下这个文档的内容"}
    ],
    stream=False,
    extra_body={
        "extra_body": {
            "reference": True,  # 返回引用的文档片段
            "reference_metadata": {
                "include": True,
                "fields": ["author", "source"]
            }
        }
    }
)

# 获取回答
print(response.choices[0].message.content)

# 获取引用的文档来源
print(response.choices[0].message.reference)

# 方式二：直接调用 HTTP API

如果你需要更底层的控制，可以直接调用 RAGFlow 的 RESTful API。

# 认证方式

所有 API 请求需要在 Header 中携带 Bearer Token：

http

Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

# 核心 API 端点

功能 方法 端点 说明
创建知识库 POST /api/v1/datasets 创建新的数据集
列出知识库 GET /api/v1/datasets 获取所有数据集列表
上传文档 POST /api/v1/datasets/{dataset_id}/documents 上传文件到指定数据集
对话检索 POST /api/v1/chats_openai/{chat_id}/chat/completions OpenAI 兼容的对话接口
管理智能代理 POST /api/v1/canvas/completion 执行 Agent 画布流程

# Python requests 示例

python

import requests

BASE_URL = "http://your-ragflow-address:9380"
API_KEY = "your-api-key"
HEADERS = {
    "Authorization": f"Bearer {API_KEY}",
    "Content-Type": "application/json"
}

# 1. 创建知识库
def create_dataset(name):
    response = requests.post(
        f"{BASE_URL}/api/v1/datasets",
        headers=HEADERS,
        json={"name": name}
    )
    return response.json()

# 2. 对话检索
def chat_with_rag(chat_id, question):
    response = requests.post(
        f"{BASE_URL}/api/v1/chats_openai/{chat_id}/chat/completions",
        headers=HEADERS,
        json={
            "model": "model",
            "messages": [{"role": "user", "content": question}],
            "stream": False
        }
    )
    return response.json()

# 场景2：构建自定义 RAG 应用

python

from openai import OpenAI
from flask import Flask, request, jsonify

app = Flask(__name__)

# 初始化 RAGFlow 对话客户端
client = OpenAI(
    api_key="ragflow-key",
    base_url="http://localhost:9380/api/v1/chats_openai/your_chat_id"
)

@app.route("/ask", methods=["POST"])
def ask():
    question = request.json.get("question")
    
    response = client.chat.completions.create(
        model="model",
        messages=[{"role": "user", "content": question}],
        extra_body={"extra_body": {"reference": True}}
    )
    
    return jsonify({
        "answer": response.choices[0].message.content,
        "references": response.choices[0].message.reference
    })

if __name__ == "__main__":
    app.run(port=5000)

# 📚 总结

RAGFlow 提供了完整的 Python 二次开发能力：

  1. 官方 SDK (ragflow-sdk) 封装了核心功能，上手最快
  2. HTTP API 覆盖了所有功能，包括知识库管理、文档上传、对话检索和 Agent 画布
  3. OpenAI 兼容接口 让你可以无缝复用现有的 OpenAI 客户端代码
  4. 支持流式响应，适合构建实时对话应用

建议从官方 SDK 开始，如果需要更精细的控制或 SDK 暂未覆盖的功能，再切换到原生 HTTP API 调用。
